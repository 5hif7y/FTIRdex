\section{Conclusiones}
% ==========================================
La biblioteca \texttt{ftir\_library} v0.0.3 consolida un entorno unificado de caracterización y diagnóstico de espectros vibracionales. La simplificación de su API mediante funciones que automatizan las correcciones y grid searches minimiza el error de uso en laboratorios químicos y oncológicos, mientras que el clasificador Kernel Ridge con kernel RBF aporta una precisión binaria robusta del 99.58\% para la detección de melanoma.
