\maketitle

\begin{abstract}
Este informe presenta el diseño matemático, algorítmico e ingenieril del sistema automático de procesamiento y análisis espectroscópico integrado en la versión 0.0.4 de la biblioteca. El sistema está diseñado para abordar dos técnicas espectroscópicas de alta relevancia biomédica y fisicoquímica: la espectroscopía infrarroja por transformada de Fourier (FTIR) aplicada al análisis estructural del Óxido de Grafeno (GO y rGO) y muestreo de bases de datos clásicas del NIST, y la espectroscopía Raman SERS (Surface-Enhanced Raman Spectroscopy) aplicada al diagnóstico automático de células cancerosas (melanoma). Se detallan los algoritmos de suavizado local (Savitzky-Golay, percentiles), remoción de deriva de línea base (AsLS, airPLS, arPLS) y el filtro de rayos cósmicos basado en desviaciones absolutas respecto a la mediana (MAD). En esta versión 0.0.4 se desacopla el módulo estadístico, integrando Análisis de Componentes Principales (PCA) mediante SVD y el clasificador Kernel Ridge con kernel RBF, logrando clasificar la calidad de proveedores de grafeno con 100\% de precisión en validación cruzada y automatizar el muestreo de archivos JCAMP-DX mediante una nueva API simplificada con constantes RAW/NONE.
\end{abstract}
